Week 6 - Git fundamentals

5 exercises, working through Git from basic config to conflict resolution.

exercise1 - git config, notepad++ as default editor, first commit, connecting to GitLab
exercise2 - .gitignore, ignoring .log files and a log folder
exercise3 - branching, diffing, merging, GitLab merge requests
exercise4 - resolving an actual merge conflict, .gitignore for backup files
exercise5 - final pull/push cleanup back to remote

exercises 2-4 were run for real in a GitDemo repo while working through this, so
the command output in those READMEs is copy-pasted straight from the terminal, not
made up. exercises 1 and 5 depend on stuff specific to my own machine and GitLab
account (installing notepad++, signing up on gitlab, pushing to my own remote) so
those are written as the exact commands to run rather than something pre-run.

exercise5/final-repo-snapshot/ has the plain end-state files (welcome.txt,
feature.txt, hello.xml, .gitignore) with no .git folder, just in case it's useful
to compare against later.

to work through this: start with exercise1's readme (sets up git config, notepad++,
and the GitDemo project on gitlab), then go in order 2 -> 5, running everything in
the same GitDemo folder each time.
